Structured outputs

Stop parsing hopeful text — guarantee the JSON, or the tool arguments.

Domain 6.3 · Output Handling Domain 8.1 · Tools

Coaxing valid JSON with prompts works… until it doesn’t, at 3am, on row 4,000. Structured outputs make the shape a guarantee via grammar-constrained decoding. Two flavours: constrain the response text, or constrain a tool call’s arguments.

Your win: get back JSON that is guaranteed to parse, and make a tool’s arguments schema-valid with one flag.

Read alongside The structured-outputs sheet: output_config.format for response JSON, strict:true for tool arguments; both behind a beta header; incompatible with citations and prefilling.

Do it

  1. Guarantee a JSON response with a schema: 
    schema = {"type": "object",
          "properties": {"name": {"type": "string"}, "age": {"type": "integer"}},
          "required": ["name", "age"]}

resp = client.messages.create(
    model="claude-sonnet-5", max_tokens=200,
    output_config={"format": {"type": "json_schema", "schema": schema}},
    messages=[{"role": "user", "content": "Extract: John Doe is 30 years old."}],
)
import json
data = json.loads(resp.content[0].text)     # will not throw
  2. Prefer Pydantic? Let the SDK build the schema and parse the reply: 
    from pydantic import BaseModel
class User(BaseModel):
    name: str
    age: int

msg = client.messages.parse(
    model="claude-sonnet-5", max_tokens=200, output_format=User,
    messages=[{"role": "user", "content": "Extract: John Doe is 30 years old."}],
)
  3. Inside a tool loop, pin the arguments instead with strict: true: 
    tools = [{"name": "record_user",
          "description": "Save a user record.",
          "input_schema": schema,
          "strict": True}]     # tool_use.input is guaranteed schema-valid
Guaranteed shape is not guaranteed truth Only a subset of JSON Schema is enforced — keywords like minimum become description hints, not hard constraints. And a schema-valid object can still be wrong. Keep validating; stay skeptical of confident output.
