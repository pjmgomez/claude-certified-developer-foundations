Phase 1 · Core API Mechanics

Images and documents in, text out

Same Messages envelope — just richer content blocks.

Domain 2.3 · Vision & multi-format input

A user turn’s content can be a list of blocks that mixes text with image or document blocks. Nothing else about the call changes — you still read message.content[0].text on the way out.

Your win: ask Claude a question about a local image, then swap in an image URL and a PDF.

Do it

  1. Send a local image as a base64 block beside a text block: 
    import base64, anthropic

client = anthropic.Anthropic()

with open("chart.png", "rb") as f:
    b64 = base64.standard_b64encode(f.read()).decode("utf-8")

msg = client.messages.create(
    model="claude-sonnet-5", max_tokens=300,
    messages=[{
        "role": "user",
        "content": [
            {"type": "image",
             "source": {"type": "base64", "media_type": "image/png", "data": b64}},
            {"type": "text", "text": "What does this chart show? Be specific."},
        ],
    }],
)
print(msg.content[0].text)
  2. Swap the source for a hosted image — no encoding needed: 
    {"type": "image", "source": {"type": "url", "url": "https://example.com/cat.png"}}
  3. Ask about a PDF with a document block: 
    {"type": "document",
 "source": {"type": "base64", "media_type": "application/pdf", "data": pdf_b64}}
Verify the limits Common image types are image/jpeg, image/png, image/gif, image/webp. Exact supported formats, per-image size caps, and page limits for PDFs change — confirm on the vision / PDF docs before you rely on them in production.
