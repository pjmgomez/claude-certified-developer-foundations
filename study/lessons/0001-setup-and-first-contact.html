Phase 0 · Setup & First Contact

Your first words with Claude

Get the environment working and make one real API call — then read exactly what it cost.

Domain 2.3 · API Mechanics Domain 7.4 · Secrets & Keys Foundation for everything

You already write software; what is new is the shape of a Claude program. Almost everything in this course — streaming, tools, agents, caching — is a variation on the loop you are about to run: send messages, get a Message back, inspect it. Nail this once and the rest is elaboration.

Your win for this lesson: a live reply from Claude in your terminal, plus the token counts that every cost decision later in the course is built on.

Primary source Read the Get started guide and skim the anthropic-sdk-python README. The code below was checked against that SDK — but confirm it yourself; that habit is the point.

Do it

  1. Create an API key. Sign in at the Claude Platform Console, open API keys, and create one. Copy it now — the full key is shown only once.
  2. Put the key in your environment, never in code: 
    export ANTHROPIC_API_KEY="sk-ant-..."
    Add it to your shell profile or a .env file you keep out of git.
  3. Install the SDK in a fresh virtual environment: 
    python -m venv .venv && source .venv/bin/activate
pip install anthropic
  4. Write hello.py: 
    import anthropic

client = anthropic.Anthropic()  # reads ANTHROPIC_API_KEY from the environment

message = client.messages.create(
    model="claude-sonnet-5",     # verify current IDs at platform.claude.com/docs
    max_tokens=200,
    messages=[
        {"role": "user", "content": "In one sentence, what is the Claude Messages API?"},
    ],
)

print(message.content[0].text)          # the reply is a list of content blocks
print("stop_reason:", message.stop_reason)
print("input tokens:", message.usage.input_tokens)
print("output tokens:", message.usage.output_tokens)
  5. Run it: python hello.py. You should see a one-sentence answer, stop_reason: end_turn, and two token counts.
  6. Poke it. Ask for a paragraph instead of a sentence and rerun. Watch output_tokens climb while input_tokens barely moves. That asymmetry is why output is the expensive side of the bill.
Verify, don’t trust Model IDs and prices drift. claude-sonnet-5 and claude-haiku-4-5 appear in current official examples, but always confirm the live ID on the models page before shipping. Treating any identifier or price as provisional-until-checked is a durable exam skill.
Security — treat this as reflex The key is a bearer credential: anyone holding it can spend your money. Keep it in an environment variable or secrets manager, never in source or a committed file. Rotate it if it leaks. A bad or revoked key is how you earn a 401 authentication_error — we cover that taxonomy in Phase 1.

Check yourself

Answer from memory before you scroll back — retrieval is what makes it stick.
