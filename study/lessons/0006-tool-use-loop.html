The tool-use loop

Let Claude call your code, hand back the result, and continue — the heartbeat of every agent.

Domain 8.1 · Tool Implementation Domain 8 = 10.6%

A tool is a function you describe to Claude. When Claude decides to use one, it doesn’t run anything — it asks you to, by returning a tool_use block. You execute the function and return a tool_result. Loop until Claude is done. That is the entire mechanism behind agents.

Your win: a working loop where Claude calls a get_weather tool, you feed the result back, and it answers in natural language.

The four beats 1) You send tools. 2) Claude replies with stop_reason: "tool_use" and one or more tool_use blocks. 3) You run each and return tool_result blocks (matched by tool_use_id). 4) Claude uses them to answer — or asks for another tool.

Do it

  1. Define a tool and its implementation: 
    import anthropic

client = anthropic.Anthropic()
MODEL = "claude-sonnet-5"

tools = [{
    "name": "get_weather",
    "description": "Get the current weather for a city. Returns a short text summary.",
    "input_schema": {
        "type": "object",
        "properties": {"city": {"type": "string", "description": "City name, e.g. 'Paris'"}},
        "required": ["city"],
    },
}]

def get_weather(city):                 # your real logic would call an API
    return f"It is 21C and sunny in {city}."
  2. Run the loop — keep going while Claude wants a tool: 
    messages = [{"role": "user", "content": "What's the weather in Paris?"}]
resp = client.messages.create(model=MODEL, max_tokens=400, tools=tools, messages=messages)

while resp.stop_reason == "tool_use":
    messages.append({"role": "assistant", "content": resp.content})   # replay Claude's turn
    results = []
    for block in resp.content:
        if block.type == "tool_use":
            out = get_weather(**block.input)          # execute
            results.append({
                "type": "tool_result",
                "tool_use_id": block.id,              # must match the call
                "content": out,
            })
    messages.append({"role": "user", "content": results})             # hand results back
    resp = client.messages.create(model=MODEL, max_tokens=400, tools=tools, messages=messages)

print(resp.content[0].text)
  3. Make the tool raise, and return {"type":"tool_result","tool_use_id":...,"content":"error text","is_error": True}. Watch Claude recover gracefully instead of crashing.
