Phase 5 · Agents & Workflows

Subagents & hooks

Delegate to isolated helpers; wire deterministic guardrails into the loop.

Domain 1.2 · Agent Construction

Two ways to shape an agent’s behaviour beyond its prompt: subagents hand a sub-task to a helper with its own context window, and hooks run your code at lifecycle events to observe, block, or transform — deterministically, not by asking nicely.

Your win: define a specialist subagent and register a PreToolUse hook on the agent loop.

Read alongside The Agent SDK sheet. Hooks get the full treatment in Phase 7 (security); here we just wire them into the SDK.

Do it

  1. Define a specialist subagent — it runs in its own context and returns just its result: 
    from claude_agent_sdk import ClaudeAgentOptions, AgentDefinition, query

options = ClaudeAgentOptions(agents={
    "reviewer": AgentDefinition(
        description="Reviews code for bugs and security issues",
        prompt="You are a meticulous code reviewer.",
        tools=["Read", "Grep"],
        model="sonnet",
    ),
})
    The parent delegates to reviewer; the reviewer’s intermediate steps never clutter the parent’s window (the context-isolation idea from Phase 4).
  2. Register a hook that fires before any Write tool call: 
    from claude_agent_sdk import ClaudeSDKClient, ClaudeAgentOptions, HookMatcher

async def guard_writes(input_data, tool_use_id, context):
    # inspect input_data (the pending tool call); return a decision to allow or deny.
    return {}   # {} = allow; return a deny decision to block (full schema in Phase 7)

options = ClaudeAgentOptions(
    allowed_tools=["Write"],
    hooks={"PreToolUse": [HookMatcher(matcher="Write", hooks=[guard_writes])]},
)
  3. Reflect: subagents shape what work happens where; hooks shape what’s allowed to happen. Prompts are “should”; hooks are “must.”
Deployment & auth Run the SDK self-hosted (your own API key) or Anthropic-managed; it can route to the Anthropic API, Bedrock, or Vertex. Use API-key auth — third-party products can’t offer claude.ai login for SDK-built apps.
