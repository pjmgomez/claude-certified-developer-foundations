Context editing, compaction & memory

Let the platform prune, summarise, and remember — so long runs don’t rot.

Domain 6.1 · Context Engineering

Manual pruning (last lesson) gets you far; for long agents you want the platform to do it. Three managed tools: context editing clears old tool results, compaction summarises older turns, and the memory tool persists facts to files across conversations.

Your win: configure context editing so an agent auto-clears stale tool results while protecting its memory.

Read alongside The context-management sheet. All of this is beta — use client.beta.messages with the context-management-2025-06-27 header.

Do it

  1. Auto-clear old tool results once the window grows — but never clear memory: 
    ctx = {"edits": [{
    "type": "clear_tool_uses_20250919",
    "trigger": {"type": "input_tokens", "value": 30000},   # clear when input passes 30k
    "keep":    {"type": "tool_uses",    "value": 3},       # retain the 3 most recent
    "exclude_tools": ["memory"],                            # protect memory writes
}]}

resp = client.beta.messages.create(
    model="claude-sonnet-5", max_tokens=1024,
    betas=["context-management-2025-06-27"],
    context_management=ctx,
    tools=[...], messages=[...],
)
for e in (resp.context_management.applied_edits if resp.context_management else []):
    print("applied:", e.type, e.cleared_input_tokens)
  2. Prefer summarising over deleting? Swap in server-side compaction: 
    ctx = {"edits": [{"type": "compact_20260112"}]}   # trigger defaults to ~150k input tokens
  3. Add durable memory with the memory tool (CRUD over /memories), and keep it in exclude_tools so editing never erases it: 
    tools = [{"type": "memory_20250818", "name": "memory"}]   # SDK: BetaLocalFilesystemMemoryTool
Editing + memory is the combo Anthropic reports memory + context editing beat baseline by ~39% (editing alone ~29%), with up to 84% fewer tokens on a long web-search eval. The trap: if you clear tool uses without excluding memory, you delete the very notes you're relying on.
