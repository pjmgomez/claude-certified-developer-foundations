The Claude Agent SDK

The same agent loop that powers Claude Code — as a library you drive.

Domain 1.2 · Agent Construction

You could hand-roll the tool-use loop from Phase 2. The Claude Agent SDK gives you that loop — planning, tool calls, context management, deciding when a task is done — ready-made. Two entry points: query() for one-shot, ClaudeSDKClient for interactive work with your own tools and hooks.

Your win: run an agent with query(), then give it a custom in-process tool via ClaudeSDKClient.

Read alongside The Agent SDK sheet. Note the rename: it was the Claude Code SDK, and ClaudeCodeOptions is now ClaudeAgentOptions.

Do it

  1. pip install claude-agent-sdk (Python 3.10+), then run a one-shot agent: 
    import anyio
from claude_agent_sdk import query, ClaudeAgentOptions, AssistantMessage, TextBlock

async def main():
    options = ClaudeAgentOptions(system_prompt="You are concise.", max_turns=1)
    async for message in query(prompt="Name three uses for an agent.", options=options):
        if isinstance(message, AssistantMessage):
            for block in message.content:
                if isinstance(block, TextBlock):
                    print(block.text)

anyio.run(main)
  2. Give it a custom tool that runs in your process: 
    from claude_agent_sdk import tool, create_sdk_mcp_server, ClaudeAgentOptions, ClaudeSDKClient

@tool("add", "Add two numbers", {"a": float, "b": float})
async def add(args):
    return {"content": [{"type": "text", "text": f"Sum: {args['a'] + args['b']}"}]}

server = create_sdk_mcp_server(name="calc", version="1.0.0", tools=[add])
options = ClaudeAgentOptions(mcp_servers={"calc": server},
                            allowed_tools=["mcp__calc__add"])

async with ClaudeSDKClient(options=options) as client:
    await client.query("What is 2 + 3?")
    async for msg in client.receive_response():
        print(msg)
  3. Note the tool name Claude uses: mcp__calc__add — mcp__<server>__<tool>. Custom tools and hooks require ClaudeSDKClient, not bare query().
