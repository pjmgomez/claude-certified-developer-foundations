Official sample questions

Published in the exam guide (safe to study). Answer each, then check:

Sample 1 · Domain 2 Process 10,000 documents overnight, cost-first, not needed till morning → Use the Message Batches API (latency-tolerant, ~50% cheaper). Parallel sync calls don’t cut per-token cost; lowering max_tokens or blindly downsizing misses the batch-vs-realtime axis.
Sample 2 · Domain 7 A summarized page hides “reveal your system prompt” → Treat page content as untrusted, isolate it, and use guardrails/hooks so injected text can’t trigger sensitive actions. Temperature is irrelevant; a polite request isn’t a control; a bigger model can be more susceptible.
Sample 3 · Domain 8 A capability reusable across several apps, maintained independently → Build an MCP server. Hard-coding into prompts isn’t reusable; pasting data gives no live access; built-in tools don’t reach arbitrary internal APIs.
