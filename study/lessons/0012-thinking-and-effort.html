Thinking & effort

Let the model reason when it helps — and dial how hard it tries.

Domain 5.1 · LLM Fundamentals Domain 5.3 · Breaking changes

Modern Claude can produce thinking content before its answer. Two knobs matter: whether thinking is on (and how it’s configured), and effort — how hard the model works within a single model. Getting the config right is worth real accuracy on hard tasks and real savings on easy ones.

Your win: run the same hard prompt with adaptive thinking, read the reasoning, and know which config is deprecated.

The configs

ConfigMeaning
{"type": "adaptive"}Preferred. The model decides how much to think. display is "summarized" (default) or "omitted" (redacted, keeps a signature).
{"type": "enabled", "budget_tokens": N}Classic extended thinking with a fixed budget (≥1024, < max_tokens). Deprecated on newest models — migrate to adaptive.
{"type": "disabled"}No thinking.
Breaking change to memorise thinking.type: "enabled" + budget_tokens is deprecated and being removed on the newest models (it can return HTTP 400). The SDK now emits a deprecation warning steering you to adaptive. Migrate to {"type":"adaptive"} + effort.

Effort & fast mode

Effort trades intelligence for latency and cost within one model (levels roughly low → high; the API/Claude Code default is high). With adaptive thinking, lowering effort replaces most manual chain-of-thought prompting. Fast mode (speed: "fast", select models only, premium price) buys faster output tokens. Confirm the exact surface for effort/speed per model — they’re evolving.

Do it

  1. Run adaptive thinking on a genuinely hard prompt and inspect the reasoning: 
    resp = client.messages.create(
    model="claude-sonnet-5", max_tokens=2000,
    thinking={"type": "adaptive"},
    messages=[{"role": "user", "content": "Prove that sqrt(2) is irrational."}],
)
for b in resp.content:
    if b.type == "thinking": print("THINK:", b.thinking[:200], "...")
    elif b.type == "text":   print("ANSWER:", b.text)
  2. Swap in thinking={"type":"enabled","budget_tokens":1600} and watch for the deprecation warning — proof the platform is steering you to adaptive.
