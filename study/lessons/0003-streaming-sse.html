Streaming, event by event

Show tokens as they land — and know the exact event order behind the magic.

Domain 2.3 · API Mechanics Domain 5.2 · Technical Fundamentals

A non-streamed call blocks until the whole answer is ready. Streaming delivers the reply incrementally over Server-Sent Events (one-way HTTP, not WebSockets), so a UI can render as Claude types. The SDK gives you an ergonomic helper and the raw event stream underneath.

Your win: stream a reply to the terminal live, then reconstruct the final message and read its usage — and separately watch the raw event names go by.

Read alongside Keep the SSE event-flow reference open. The order is fixed: message_start → content_block_start → content_block_delta… → content_block_stop → message_delta → message_stop (with pings sprinkled in).

Do it

  1. Stream with the helper and print text as it arrives: 
    import anthropic

client = anthropic.Anthropic()
MODEL = "claude-sonnet-5"

with client.messages.stream(
    model=MODEL, max_tokens=300,
    messages=[{"role": "user", "content": "Write a haiku about streaming."}],
) as stream:
    for event in stream:
        if event.type == "text":            # a text_delta helper event
            print(event.text, end="", flush=True)
print()

final = stream.get_final_message()          # full Message, accumulated for you
print("stop_reason:", final.stop_reason,
      "| output tokens:", final.usage.output_tokens)
  2. Now watch the raw events to see the order for yourself: 
    raw = client.messages.create(
    model=MODEL, max_tokens=100, stream=True,
    messages=[{"role": "user", "content": "Say hi in three words."}],
)
for event in raw:
    print(event.type)    # message_start, content_block_start, content_block_delta, ...
  3. Confirm you see input tokens on message_start and the final stop_reason + output tokens on message_delta — there is no single “usage” event.
Why it matters later Tool calls stream too — their arguments arrive as input_json_delta fragments (partial_json) that you concatenate and parse once. Same envelope, different delta type.
