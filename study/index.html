How to use this Work top to bottom. Each lesson is one win: read it, run its Python lab, take the quiz from memory, then move on. Reference sheets are for quick review and printing. Start with MISSION.md for the why; track progress in NOTES.md.
Daily spaced review Once you’ve worked through a few phases, open the spaced-review drill each day — interleaved retrieval across all domains, scheduled (Leitner boxes) so the exam-critical facts move into long-term memory. A few minutes daily beats re-reading.
