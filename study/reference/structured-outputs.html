Two ways to guarantee valid shapes — response JSON, or tool arguments.

They can be combined in one request. Both are gated behind a beta header (e.g. structured-outputs-2025-12-15 — verify the current value).

schema = {"type": "object",
          "properties": {"name": {"type": "string"}, "age": {"type": "integer"}},
          "required": ["name", "age"]}

resp = client.messages.create(
    model="claude-sonnet-5", max_tokens=200,
    output_config={"format": {"type": "json_schema", "schema": schema}},
    messages=[{"role": "user", "content": "Extract: John Doe is 30."}],
)
import json
data = json.loads(resp.content[0].text)     # guaranteed to parse

SDK helper: client.messages.parse(output_format=PydanticModel, ...) converts a Pydantic model to output_config.format and parses the reply for you. (The older output_format= keyword is deprecated in favour of output_config.format.)

Sharp edges Incompatible with citations and prefilling. Only a subset of JSON Schema is enforced — unsupported keywords (like minimum) become description hints your code must still check. The schema is compiled and cached (~24h). Validate anyway: guaranteed shape is not guaranteed correctness.
