MCP essentials

Primitives, transports, lifecycle, and the smallest server that works.

Domain 8.2 · MCP Server Development

The Model Context Protocol is an open, JSON-RPC 2.0, stateful client–server protocol that standardises how an AI app connects to external tools and data. Write a server once; any MCP-speaking client (Claude Code, Claude Desktop, your SDK app) can use it.

Primitives
PrimitiveWhat it is
ToolsExecutable functions with JSON-Schema inputs (model-controlled).
ResourcesURI-addressed, read-only data (application-controlled).
PromptsReusable prompt templates (user-controlled).
Sampling (advanced)The server asks the client’s LLM to generate.
Roots (advanced)Client-provided scoped access boundaries.
Transports
TransportUse
stdioLocal subprocess over stdin/stdout. The default; not sandboxed — it runs with your privileges.
Streamable HTTPRemote server on a port (HTTP + optional SSE). (Plain SSE transport is superseded.)

Lifecycle: initialization → capability negotiation → normal operation (tools/list, tools/call, resources/list, prompts/list, …) → shutdown.

Smallest Python server

from mcp.server.mcpserver import MCPServer   # formerly named FastMCP

mcp = MCPServer("inventory")

@mcp.tool()
def stock_level(sku: str) -> int:
    """Units in stock for a SKU."""
    return {"A1": 12, "B2": 0}.get(sku, 0)

@mcp.resource("inventory://skus")
def all_skus() -> str:
    """Every known SKU, one per line."""
    return "A1\nB2"

@mcp.prompt()
def restock_note(sku: str) -> str:
    """Draft a restock request."""
    return f"Write a short restock request for SKU {sku}."

if __name__ == "__main__":
    mcp.run()            # stdio by default; mcp.run(transport="streamable-http") for a port

CLI: mcp dev server.py (Inspector) · mcp run server.py · mcp install (Claude Desktop). Wire into Claude Code with claude mcp add (verify flags in the Claude Code docs).
