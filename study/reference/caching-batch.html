Cost levers: caching & batch

Two big discounts — a warm prefix, and latency-tolerant bulk.

Domain 5.4 · Cost & Token Management

Prompt caching

Mark a stable prefix (system prompt, tools, long context) with a cache_control breakpoint. Reuse within the TTL and you pay a fraction to re-read it.

system=[{"type": "text", "text": BIG_STABLE_PROMPT,
         "cache_control": {"type": "ephemeral"}}]        # ttl defaults to "5m"; or "1h"
Multipliers vs. the base input price (PROVISIONAL — verify)
EventCost
Cache read (hit)0.1× — 10% of base input
Cache write, 5-minute TTL1.25× base
Cache write, 1-hour TTL2× base

It pays off after one read (5-minute) or two reads (1-hour). Default TTL is 5 minutes. max_tokens: 0 pre-warms the cache without generating.

Cache check-pointing = where you place breakpoints. Automatic: a top-level cache_control marks the last cacheable block and moves forward as the conversation grows. Explicit: put cache_control on specific blocks. Longer-TTL entries must precede shorter ones.

Read it back in usage:

usage.input_tokens                 # uncached input
usage.cache_creation_input_tokens  # tokens written to cache (billed at write rate)
usage.cache_read_input_tokens      # tokens served from cache (billed at 0.1x)
usage.cache_creation.ephemeral_5m_input_tokens / ephemeral_1h_input_tokens
# total input = input_tokens + cache_creation_input_tokens + cache_read_input_tokens

Message Batches API

batch = client.messages.batches.create(requests=[
    {"custom_id": "doc-1",
     "params": {"model": "claude-haiku-4-5", "max_tokens": 200,
                "messages": [{"role": "user", "content": "Classify: ..."}]}},
])
  • 50% off input and output.
  • Up to 100,000 requests or 256 MB, whichever comes first.
  • Asynchronous; most finish within 1 hour, and batches expire if not done within 24 hours. Results are retrievable for 29 days. Scoped to a Workspace.
  • Each request carries a custom_id to match its result. No streaming, no interactive tool loops.
Realtime vs batch Anything user-facing → realtime (sync / streaming). Offline evals, bulk classification, dataset labelling — anything tolerant of up to 24h → batch, at half price.
