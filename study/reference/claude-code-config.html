Pin explicit versions in production; re-test on every upgrade. Changing tool_choice, thinking config, or budget_tokens invalidates prompt-cache breakpoints — version prompts alongside code.

Modes & sessions

  • Headless -p "prompt" — no TTY; reuses settings/hooks/permissions. Powers CI, cron, pre-commit, GitHub Actions. PermissionRequest hooks do not fire here; a permissionDecision: "defer" pauses a call for a wrapping process.
  • Streaming --output-format stream-json.
  • Resume --continue / --resume.

Built-in slash commands

/clear, /compact, /model, /cost, /context, /memory, /init, /doctor, /hooks, /permissions. Custom / skill-backed commands take $ARGUMENTS (or $1, $ARGUMENTS[N]).

Plugins A plugin is a self-contained .claude-plugin/plugin.json directory bundling skills, agents, hooks, and MCP servers — the unit for sharing a whole configuration.
