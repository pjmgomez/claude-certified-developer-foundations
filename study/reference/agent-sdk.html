Claude Agent SDK

Claude Code as a library: the agent loop, tools, and context management, in your code.

Domain 1.2 · Agent Construction

pip install claude-agent-sdk (Python 3.10+; also TypeScript). Formerly the Claude Code SDK — renamed ~Sept 2025, and ClaudeCodeOptions → ClaudeAgentOptions (a breaking change to remember).

Two entry points
query()ClaudeSDKClient
Async function → AsyncIterator of messages. One-shot / stateless.Interactive, multi-turn, bidirectional. Enables custom tools and hooks.
 
from claude_agent_sdk import query, ClaudeAgentOptions, AssistantMessage, TextBlock

options = ClaudeAgentOptions(system_prompt="You are concise.", max_turns=1)
async for message in query(prompt="Hello Claude", options=options):
    if isinstance(message, AssistantMessage):
        for block in message.content:
            if isinstance(block, TextBlock):
                print(block.text)

ClaudeAgentOptions (dataclass) carries: system_prompt, max_turns, allowed_tools, mcp_servers, hooks, agents, permission_mode, model, cwd, env.

Custom tools (in-process MCP)

from claude_agent_sdk import tool, create_sdk_mcp_server, ClaudeAgentOptions, ClaudeSDKClient

@tool("add", "Add two numbers", {"a": float, "b": float})
async def add(args):
    return {"content": [{"type": "text", "text": f"Sum: {args['a'] + args['b']}"}]}

server = create_sdk_mcp_server(name="calc", version="1.0.0", tools=[add])
options = ClaudeAgentOptions(mcp_servers={"calc": server},
                            allowed_tools=["mcp__calc__add"])   # note the mcp__server__tool naming

Hooks & subagents

from claude_agent_sdk import HookMatcher, AgentDefinition

options = ClaudeAgentOptions(
    hooks={"PreToolUse": [HookMatcher(matcher="Write", hooks=[my_callback])]},
    agents={"reviewer": AgentDefinition(
        description="Reviews code", prompt="You are a code reviewer.",
        tools=["Read", "Grep"], model="sonnet")},
)
Deployment Self-hosted (you run the SDK/CLI with your own API key) vs. Anthropic-managed. Provider routing targets the Anthropic API, Amazon Bedrock, or Google Vertex. Use API-key auth — third-party products can’t offer claude.ai login. For other languages, run the CLI as a subprocess with -p and --output-format stream-json.
