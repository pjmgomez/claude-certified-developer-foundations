Output is priced roughly 5× input — the asymmetry that makes verbose responses the expensive side of the bill. Previous-generation IDs (e.g. claude-opus-4-6, claude-sonnet-4-5) remain valid; know both generations.

Choosing

Pick the cheapest tier that clears your eval bar, then escalate only if it doesn’t: Haiku → Sonnet → Opus → Fable. Validate the choice with a real eval, not a hunch.

Adaptive-thinking support

Fable / Opus / Sonnet 5 (and Opus 4.6+/Sonnet 4.6) support adaptive thinking. Haiku 4.5 supports classic extended thinking but not adaptive. Confirm per model — the SDK exposes capability flags for adaptive vs enabled.

Versioning — the production trap

FormMeaning
claude-sonnet-4-5 (alias)Pointer to the latest snapshot — for pre-4.6 models only.
claude-sonnet-4-5-20250929A fixed, dated snapshot.
claude-opus-5 (dateless)Since 4.6, dateless IDs are themselves pinned snapshots — NOT evergreen pointers. A common misconception.

Pin an explicit version in production and re-test on every upgrade.
